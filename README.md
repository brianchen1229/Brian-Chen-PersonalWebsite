# Brian Chen Personal Website

This folder contains a pure HTML/CSS academic website for GitHub Pages.

## Files

- `index.html`: home and About me
- `biography.html`: research experience and education
- `publication.html`: working paper and course projects
- `conference-presentations.html`: conference presentation and slides
- `cv.html`: CV page
- `hobbies.html`: basketball achievements
- `styles.css`: all visual styling
- `script.js`: automatically updates the footer year

## Publish with GitHub Pages

Upload every file and the entire `assets` folder to the root of the
`Brian-Chen-PersonalWebsite` repository. In the repository settings, configure
GitHub Pages to deploy from the `main` branch and `/ (root)` folder.

Images, presentation files, and the CV have intentionally not been added yet.
The `assets` folder can be created later when those materials are ready.
